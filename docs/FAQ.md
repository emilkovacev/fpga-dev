# Frequently Asked Questions

## What does `32'h0` mean?

`32'h0` represents a 32-bit value, represented in hexidecimal (`h`),
with a value of `0`.

The general format is `[width]'[base][value]`, where 

* `width` is the width of the value in bits
* `base` is the base representation of the value (`b` for binary, `h` for hex, `d` for decimal
* `value` for the actual value that's being stored
