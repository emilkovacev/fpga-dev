# Quickstart

A simple, complete HDL simulation tutorial. Circuit design (Verilog), 
testbench generation (verilator), and waveform viewing (gtkwave). Code
samples were modified from examples provided by verilator in
https://github.com/verilator/verilator/tree/stable/examples/.


## Prerequisites

* [Install Verilator (ideally from source using the `stable` branch)](https://verilator.org/guide/latest/install.html)
* [Install GTKWave](https://gtkwave.github.io/gtkwave/)

## Step 1:

1. Create a directory for your project called `hdl_quickstart`. Enter the directory.

    ```
    mkdir hdl_quickstart
    cd hdl_quickstart
    ```

2. Create a simple verilog program called `top.v`.

    ``` title="top.v"
    module top(
        input wire clk,
        input reset_l,
    
        output wire [1:0] out_small,
        input [1:0] in_small
    );
    
      assign out_small = ~reset_l ? '0 : (in_small + 2'b1);
    
      initial begin
        $dumpfile("top.vcd");
        $dumpvars();
      end
    endmodule
    ```

3. Create a verilator main file called `sim_main.cpp`.

    ``` title="sim_main.cpp"
    // DESCRIPTION: Verilator: Verilog example module
    //
    // This file ONLY is placed under the Creative Commons Public Domain.
    // SPDX-FileCopyrightText: 2017 Wilson Snyder
    // SPDX-License-Identifier: CC0-1.0
    //======================================================================
    
    #include <verilated.h>
    #include "Vtop.h"
    
    int main(int argc, char** argv) {
        VerilatedContext* const contextp = new VerilatedContext;
        contextp->traceEverOn(true);
        contextp->commandArgs(argc, argv);
    
        // Construct the Verilated model, from Vtop.h generated from Verilating "top.v"
        Vtop* const top = new Vtop{contextp};
    
        top->clk = 0;
        top->reset_l = !0;
        top->in_small = 1;
    
        // Simulate until $finish
        while (!contextp->gotFinish()) {
            // 1 timeprecision period passes...
            contextp->timeInc(1);
    
            // Toggle a fast (time/2 period) clock
            top->clk = !top->clk;
    
            // Evaluate model
            top->eval();
        }
    
        // Final model cleanup
        top->final();
    
        // Return good completion status
        return 0;
    }
    ```

4. Run the `Vtop` executable generated by verilator.
    
    ```
    ./obj_dir/Vtop
    ```

5. Generate the `top.vcd` file.

    ```
    verilator -cc --exe -Wall --trace-vcd --assert --build top.v sim_main.cpp
    ```

6. Visualize the (empty) waveform from the `top.vcd` file.

    ```
    gtkwave -o top.vcd top.gtkw
    ```
