# Verilator Getting Started

A simple project that sets up a testbench for a small verilog module, and 
visualizes it using GTKWave.

The code in this directory is a slightly modified version of https://github.com/verilator/verilator/tree/master/examples/make_tracing_c, with some components removed.

## Prerequisites

* [Verilator](https://verilator.org/guide/latest/install.html)
* [GTKWave](https://gtkwave.github.io/gtkwave/)

## Run

```
make
```
